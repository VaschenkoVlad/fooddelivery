# Прототип служби доставки їжі

Навчальний консольний прототип на Java демонструє роботу замовника, ресторану-партнера та кур'єра: оформлення кошика, підтвердження й приготування замовлення, доставку та відгук. Після успішного сценарію програма показує порожній кошик, відхилення рестораном і неможливість забору.

Це лише імітація: дані зберігаються в пам'яті, маршрут показано повідомленням. Програма не використовує мережу, базу даних, оплату, реальне відстеження чи сторонні бібліотеки. Потрібен JDK 17 або новіший.

Виконайте з кореня репозиторію у PowerShell:

```powershell
$OutputEncoding = [Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()
$sources = Get-ChildItem .\src -Filter *.java | ForEach-Object { $_.FullName }
javac --release 17 -encoding UTF-8 -d .\out $sources
java "-Dfile.encoding=UTF-8" -cp .\out Main
```
